Stored Procedure with Explicit Cursor

                            CURSOR • LOOP • FETCH • CONTINUE HANDLER
                        

                        
                    

                    

                        Iterates over all active bookings row-by-row using a MySQL explicit cursor, evaluates outstanding balances using stored function get_pending_rent(booking_id), categorizes payment status, and builds a temporary report table.
                    

                    
-- Cursor Definition Preview:
DECLARE cur_bookings CURSOR FOR
    SELECT bk.booking_id, t.name, p.name, bk.monthly_rent
    FROM Booking bk ... WHERE bk.booking_status = 'Active';
DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = TRUE;
OPEN cur_bookings;
read_loop: LOOP
    FETCH cur_bookings INTO ...;
    IF done THEN LEAVE read_loop; END IF;
    SET cur_pending = get_pending_rent(cur_booking_id);
    INSERT INTO temp_dues_report ...;
END LOOP;
CLOSE cur_bookings;

                


                

                    

                        

                            
Stored Function 1: get_pending_rent(booking_id)

                            
Calculates months elapsed × monthly rent minus sum of payments credited.

                            
SELECT booking_id, monthly_rent, 
       get_pending_rent(booking_id) AS pending_due 
FROM Booking LIMIT 5;

                            
                        

                    

                    

                        

                            
Stored Function 2: get_occupancy_percentage(property_id)

                            
Computes live occupied beds divided by total beds for a given property ID.

                            
SELECT property_id, name, 
       get_occupancy_percentage(property_id) AS occupancy_pct 
FROM Property;
